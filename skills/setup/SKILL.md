# Заготовка проекта

1. Из корня проекта выполнить `sh "${CLAUDE_SKILL_DIR}/setup.sh"` — скрипт лежит рядом с этим файлом.
2. Передать владельцу вывод скрипта как есть и одну строку: разделы AGENTS.md заполняет он, правила проекта главнее
   общих принципов навыка `review`.

Сверх скрипта ничего не создавать и не заполнять.
