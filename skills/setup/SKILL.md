# Заготовка проекта

1. Из корня проекта выполнить скрипт `setup.sh` из каталога этого навыка: `sh "<каталог этого навыка>/setup.sh"`.
2. Вывести владельцу вывод скрипта без изменений и строку: «Заполните разделы `AGENTS.md` (вручную или отдельной просьбой агенту): правило проекта главнее общего принципа».
3. Файлы сверх созданных скриптом не создавать; `AGENTS.md` не заполнять и не редактировать.
