# Заготовка проекта

1. Из корня проекта выполнить `sh "${CLAUDE_SKILL_DIR}/setup.sh"`; скрипт лежит рядом с этим файлом.
2. Ответ владельцу: вывод скрипта без изменений и строка «Заполните разделы AGENTS.md: правило проекта главнее общего
   принципа навыка `review`».
3. Файлы сверх созданных скриптом не создавать; разделы AGENTS.md не заполнять.
