# ai-skills

**Понятный и предсказуемый процесс разработки с любым ИИ-агентом: четыре навыка, у каждого своя роль, и контролируемый рост сложности.**

Четыре навыка задают агенту процесс работы и общие принципы кода без привязки к стеку или конкретному агенту. Специфику проекта (архитектуру, границы, команды, проверки) вы пишете в `AGENTS.md`, а навыки её читают и соблюдают.

Все навыки запускаются **только по явному вызову** (`/setup`, `/spec`, `/impl`, `/review`), поэтому не мешают обычным обсуждениям и быстрым правкам.

**Сильнее всего на качество влияют архитектура проекта и границы модулей, заданные в `AGENTS.md`.** Процесс и принципы удерживают код в этих рамках, но сами рамки задаёте вы.

## Зачем

- **Быстрый старт.** После `/setup` у нового или существующего проекта есть процесс: где лежат задачи, как их обсуждать, реализовывать и проверять. Существующие файлы не перезаписываются.
- **Контролируемый рост сложности.** Каждое решение проверяется по базовым принципам (`review/principles.md`) и правилам проекта из `AGENTS.md` на всех этапах: в спеке, в реализации и на ревью.
- **Оптимальное решение под задачу.** До написания кода агент сравнивает альтернативные подходы и помогает найти оптимальное решение с учётом ограничений. Факты он выясняет сам по коду, а спрашивает только о том, что меняет результат: варианты, их цена и рекомендация.
- **Правила растут вместе с проектом.** Свои принципы и критерии вы дописываете в `AGENTS.md`, и весь процесс сразу их учитывает. Правило проекта главнее общего.

## Как работает

```
/setup           заготовка AGENTS.md, spec/actual/, spec/archive/ и docs/ без перезаписи
/spec <задача>   обсуждение без кода → вопросы с рекомендациями → спека → проверка свежим агентом
/impl NNN        реализация целиком → лог с доказательствами → ревью свежим агентом → архив
/review          ревью спеки, коммитов или незакоммиченного по тем же принципам → «исправь 1–3»
```

Задачи в работе лежат в `spec/actual/`, выполненные уходят в `spec/archive/`, поэтому история решений всегда под рукой.

## Начать

```bash
npx skills add AlexanderGureev/ai-skills
```

Затем в проекте запустить `/setup`, заполнить разделы `AGENTS.md` и начать с `/spec <задача>`.
