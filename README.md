# ai-skills

**Понятный и предсказуемый процесс разработки с агентом: три навыка, у каждого своя роль, и контролируемый рост
сложности.**

Три навыка задают агенту процесс работы и базовые принципы кода. Специфику проекта (архитектуру, границы, команды,
проверки) вы пишете в `AGENTS.md`, а навыки её читают и соблюдают.

**Сильнее всего на качество влияют архитектура проекта и границы модулей, заданные в `AGENTS.md`.** Процесс и
принципы удерживают код в этих рамках, но сами рамки задаёте вы.

## Зачем

- **Быстрый старт.** После `/setup` у нового проекта есть процесс: где лежат задачи, как их обсуждать, реализовывать
  и проверять.
- **Контролируемый рост сложности.** Каждое решение проверяется по базовым принципам и правилам проекта из
  `AGENTS.md` на всех этапах: в спеке, в реализации и на ревью.
- **Оптимальное решение под задачу.** До написания кода агент сравнивает альтернативные подходы и помогает найти
  оптимальное решение с учётом ограничений. Факты он выясняет сам по коду, а спрашивает только о том, что меняет
  результат: варианты, их цена и рекомендация.
- **Правила растут вместе с проектом.** Свои принципы и критерии вы дописываете в `AGENTS.md`, и весь процесс сразу их
  учитывает. Правило проекта главнее общего.

## Как работает

```
/spec <задача>   обсуждение без кода → вопросы с рекомендациями → спека → проверка свежим агентом
/impl NNN        реализация целиком → лог с доказательствами → ревью свежим агентом → архив
/review          ревью спеки, коммитов или незакоммиченного по тем же принципам → «исправь 1–3»
```

Задачи в работе лежат в `spec/actual/`, выполненные уходят в `spec/archive/`, поэтому история решений всегда под рукой.

## Начать

```bash
npx skills add AlexanderGureev/ai-skills
```

Затем в проекте запустить `/setup`, заполнить разделы `AGENTS.md` и начать с `/spec <задача>`.
